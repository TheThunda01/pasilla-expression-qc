# References and source coverage

The [reference audit](reference-audit.json) records the actual access level, supported claims, and limits for each source. A citation is not evidence that this project ran the cited software or reproduced the cited experiment.

## How to read the evidence

Full-text access means relevant passages were accessible, not that every supplement or cited reference was reviewed. Abstract appraisal supports only the limited scope recorded in the audit. Unavailable and metadata-only sources remain visibly unresolved; historical source records and data have not been silently replaced.
