# Sources, implementation, and attribution

The source review for version 0.3.0 was refreshed on **2026-10-20**, with a [targeted follow-up on 2026-10-21](review-2026-10-21.md). Complete metadata and the recorded access levels are in [References](references.md) and the [reference audit](reference-audit.json). The distinction below matters: reading a method's documentation is not the same as running or validating that software.

| Source | What it supports here | What this repository does with it |
| --- | --- | --- |
| [Anders and Huber (2010)](https://doi.org/10.1186/gb-2010-11-10-r106) | Geometric reference counts and median-ratio size factors; sensitivity of total-count scaling to highly expressed genes. | Independently implements the normalization calculation, with its exact log-median convention documented. No dispersion or differential-expression model is fitted. |
| [Current DESeq2 vignette](https://bioconductor.org/packages/release/bioc/vignettes/DESeq2/inst/doc/DESeq2.html), document dated 2026-04-28, version 1.52.0 | Distinction between normalized counts and formal count-based inference; sample visualization and normalization assumptions. | Uses the documentation to define limitations. Does not claim to reproduce variance-stabilizing transformation (VST) or regularized logarithm (rlog) or other DESeq2 functionality. |
| [DESeq2 source at commit `76c5f8523716804dbe0a9500b4b7e216c6af225c`](https://github.com/thelovelab/DESeq2/blob/76c5f8523716804dbe0a9500b4b7e216c6af225c/R/core.R), package description 1.53.6 | Confirms that the ratio estimator uses the exponential of a median log ratio and excludes genes without finite log geometric means. | Checks the mathematical convention. The source is LGPL ≥3; no R source code is copied or bundled. This implementation is independently written in Python and adds explicit geometric centering and fixed-depth scaling. It is not claimed to be an exact software-compatible replacement. |
| [Robinson and Oshlack (2010)](https://doi.org/10.1186/gb-2010-11-3-r25) | Composition bias can make total read counts a poor proxy for the relevant relative scale. | Motivates a sensitivity comparison. Does not implement the trimmed mean of M-values (TMM, selected log expression ratios) method or assume median-ratio normalization solves every composition problem. |
| [Schönemann (1966)](https://doi.org/10.1007/BF02289451) | Historical attribution for orthogonal Procrustes alignment; primary text was unavailable in this pass. The independently written SVD calculation is separately tested. | Independently implements the SVD solution after centering and unit-Frobenius scaling, allowing reflection as well as rotation. This is a descriptive geometry calculation, not a validated biological QC threshold. |

The original experiment and derived data remain attributed in [the data notes](../data/README.md). Original Python code and documentation use this repository's MIT license. Upstream data and their preserved license information retain their own terms. No data have been silently replaced or relabeled as newly collected observations.

The 20 October review records reading Brooks et al. through PubMed metadata and abstract, with access limits for the primary full text and gene record. The 21 October follow-up recovered [PMC full text](https://pmc.ncbi.nlm.nih.gov/articles/PMC3032923/?report=xml), the [NCBI `ps` gene record](https://www.ncbi.nlm.nih.gov/gene/44258), the [pasilla data-creation vignette](https://bioconductor.org/packages/release/data/experiment/vignettes/pasilla/inst/doc/create_objects.html), and original GEO sample metadata. The archive allocation supports the package's three-treated/four-untreated pattern, while the paper text differs. The [data notes](../data/README.md) retain the unresolved derived-column mapping; no source files or sample labels were changed.

The local environment contains no R executable. Accordingly, this version makes no claim of a tested R/Bioconductor analysis. Adding DESeq2 would require an executable, tested workflow with an explicit design, an environment record, and an interpretation of the resulting model diagnostics; a code snippet alone would not supply that evidence.
